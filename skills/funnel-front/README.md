# 앞단 콘텐츠 (funnel-front)

**신청 페이지는 만들었는데, 아무도 안 들어옵니다.**

그 사이를 메우는 스킬이에요. 신청 페이지 주소 하나만 주면 **사람을 거기까지 데려오는 글**을 통으로 뽑습니다.

> 셀피쉬클럽 · 스폰지클럽에서 씁니다.

---

## 뭐가 나오나요

파일 하나 + HTML 시안 세 장.

| | 나오는 것 | 어디에 쓰나 |
|---|---|---|
| **1** | **후킹 문구 세트** | 앵글 5개. 아래 전부의 원재료 |
| **2** | **스레드 원고** | 2안, 칸 단위로 바로 붙여넣기 |
| **3** | **커뮤니티 공지문 3종** | 단톡방 / 오픈채팅 / 카페·디스코드 |
| **4** | **오프라인 카피 + 배치안** | A4 전단 · X배너 · 명함 |
| **5** | **배포 계획** | 어디에 · 몇 장 · 누구 허락 · 언제 |
| **6** | **인쇄 전 체크리스트** | 500장 날리기 전에 |
| **7** | **지금 바로 하실 일** | 내 손이 필요한 것만 체크박스로 |

**안 쓰는 채널은 안 나옵니다.** 스레드 계정이 없으면 스레드 원고는 빼고, 오프라인이 주력이면 그게 맨 앞으로 옵니다.

그리고 **열어서 Ctrl+P만 누르면 되는 HTML** 세 장이 같이 나옵니다.
`전단_A4.html` · `배너_X.html` · `명함.html` — 안에 **진짜 스캔되는 QR**이 이미 박혀 있어요. 캔바 안 열어도 됩니다.

---

## 이 스킬이 믿는 것

> **앞단 콘텐츠는 설득하는 글이 아닙니다. 한 번의 클릭과 한 번의 스캔을 얻어내는 글입니다.**

설득은 신청 페이지가 해요. 앞단에서 다 설명해 버리면 사람은 "알겠다" 하고 지나갑니다. **남겨야 눌립니다.**

그리고 하나 더 — **채널이 달라서 문구를 바꾸는 게 아니라, 사람이 그걸 마주치는 자세가 달라서** 바꿉니다.

| | 마주치는 자세 | 그래서 |
|---|---|---|
| **스레드** | 누워서 스크롤. 관심 0 | 첫 줄이 전부. 링크는 맨 뒤 |
| **전단·배너** | 걸어가며 3초. 손엔 이미 폰 | 큰 글자 하나 + 큰 QR |
| **커뮤니티** | 나를 좀 안다. 대신 방장이 본다 | 홍보 냄새 나면 끝 |

---

## 어떻게 부르나요

이렇게 말하면 알아서 켜집니다.

- "이거 어떻게 알리지"
- "사람이 안 들어와"
- "전단 만들어줘" · "명함에 QR 넣고 싶어" · "현수막 문구"
- "오픈채팅에 올릴 공지" · "단톡방에 뿌릴 글"
- "부스에서 뭘 돌리지"

**랜딩은 만들었는데 유입이 없다**는 얘기면 '홍보'라는 말을 안 해도 켜집니다.

---

## 준비물

딱 하나예요. **신청 페이지 주소.** QR을 만들어야 해서 이건 꼭 필요합니다.

나머지(뭘 주는지, 마감, 수량)는 신청 페이지를 읽어서 알아서 채웁니다. GTM 코어 문서가 있으면 그것도 같이 읽어요.

**없는 건 안 씁니다.** 신청자 수, 후기, 반응 — 아직 없으면 비워둡니다.
지어낸 "많은 분들이 신청해 주셨어요" 한 줄 때문에 전체가 광고가 되거든요.
오히려 **"아직 아무도 없습니다"가 더 세게 먹힙니다.** 먼저 들어오는 사람에겐 그게 기회니까요.

여기서 뽑은 **후킹 문구 세트를 들고** 저 스킬들로 넘어가면 말이 안 따로 놉니다.

## 인쇄하기 전에

HTML을 열고 **Ctrl+P → 대상을 "PDF로 저장"**. 인쇄 설정에서 **"배경 그래픽" 체크를 켜야** 색이 나옵니다.

그리고 이 세 가지는 꼭 하세요. 종이는 되돌릴 수 없어요.

1. **QR을 진짜 폰으로 찍어본다** — 아이폰 하나, 안드로이드 하나
2. **5~10장 먼저 뽑아서 실물로 본다**
3. **붙일 자리에 허락을 먼저 받는다** — 아파트 게시판은 관리사무소, 가게 비치는 사장님

색은 **형광색을 피하세요.** 화면에서 예쁜 순형광은 인쇄(CMYK)에서 반드시 탁해집니다.
어두운 브랜드색을 쓰실 거면 `accentText`를 `"#FFFFFF"`로 바꾸면 글자가 하얗게 됩니다.
