# selfishclub-skills

셀피쉬클럽 · 스폰지클럽에서 쓰는 클로드 스킬 모음입니다.

비개발자가 그대로 가져다 쓸 수 있게 만드는 걸 목표로 합니다. 각 스킬 폴더의 `README.md`에 무엇이 나오는지와 어떻게 부르는지가 한국어로 적혀 있습니다.

## 스킬

| 스킬 | 무엇을 하나 |
|---|---|
| [funnel-front](skills/funnel-front) | 신청 페이지는 만들었는데 아무도 안 들어올 때, 사람 끌고 오는 앞단 콘텐츠를 통으로 뽑습니다. 후킹 문구 세트 · 스레드 원고 · 커뮤니티 공지문 · QR 전단/배너/명함 카피와 배포 계획 · 인쇄용 HTML 시안(실제 스캔되는 QR 포함) |

## 쓰는 법

스킬 폴더를 통째로 `~/.claude/skills/` 아래에 넣으면 됩니다.

```
~/.claude/skills/funnel-front/
├── SKILL.md
├── references/
└── assets/
```

클로드가 `SKILL.md`의 설명을 읽고 필요한 상황에 알아서 켭니다. 폴더 이름은 바꾸지 마세요.
